# ogi-set — セット会計サポートツール

> 2026-10-09 GitHubのコード・引継ぎ記録の棚卸し。現在の店舗稼働・受託金額は未確認です。

## 目的

複数の医薬品を組み合わせたセット価格の計算を補助し、スタッフの会計判断を支援するツール。Googleスプレッドシート上でGASのダイアログを開いて利用する構成です。複数商品のセット価格や追加料金・代替商品等のルールを扱います。

## アーキテクチャ

- `Code.js`：GASの起動メニュー、ダイアログ表示、スプレッドシート「マスタ」から商品・単品価格・2種／3種セット・追加価格を読み込む処理、初期セットアップ
- `index.html`：操作画面、品目選択、セット価格の組み合わせ計算と内訳表示
- **価格の正本はスプレッドシート「マスタ」**。プログラム内の既定値はシート取得失敗時の非常用フォールバックであり、日常的な価格改定はマスタ編集を優先します。
- 既存GASのダイアログで運用する方針。スタンドアロンWebページを本番入口とは扱いません。

## 設計思想

スタッフが使うスプレッドシートを残し、複雑な料金計算の操作部分だけを画面化する現場起点の業務改善です。価格・セット定義の変更にプログラム改修を必須としない運用を目指しています。
